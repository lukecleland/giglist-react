# Western display fonts

Bundled from the Google Fonts repository, 2 October 2026. Each family includes its SIL Open Font License alongside the font file.

- Rye: https://github.com/google/fonts/tree/main/ofl/rye
- Sancreek: https://github.com/google/fonts/tree/main/ofl/sancreek
- Ewert: https://github.com/google/fonts/tree/main/ofl/ewert

Font shuffle chooses a family pairing and a plain, outline, shadow, or outline-and-shadow treatment. Giglist branding retains the Carbon font.
