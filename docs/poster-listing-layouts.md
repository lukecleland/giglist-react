# Poster listing layouts

Reference reviewed: [Glastonbury's official 2025 lineup](https://www.glastonburyfestivals.co.uk/news/glastonbury-2025-line-up-so-far/) and its full-size poster, 2 October 2026. Observed compact horizontal name rows, circular dividers, consistent baselines, separate day headings and subordinate information. The reference image is not shipped.

Use measured lineup typesetting instead of loose cloud packing. Event names remain intact on one line and shrink to fit; dates, times and locations may wrap. Preserve chronology and every occurrence of repeated names. Name size is typographic fitting, not an assertion of headliner status. Do not invent stages or billing categories.

Layouts: original columns; centred festival rows with dot, diamond or star dividers; stacked bill; two- and three-column bills; actual date sections; ruled programme; alternating bands. Programme and band layouts put details alongside names. Date sections use multiple columns for long schedules. Shuffle visits all eleven choices before repeating and shows the current style below the control.

All drawing uses the same canvas component for preview, PNG and print. Fit every listing inside the reserved listing area and keep the QR/footer clear. Validate sparse and dense bills, single-line long names, repeated names, bounds and collisions.
